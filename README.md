# 競馬予想ツール

netkeiba の公開データから、タイム・相手関係・条件適性・展開などを数値化して各馬の勝率を推定し、
3連単フォーメーション（軸1・対抗2・相手6の48点）の的中確率と期待回収率を出す。

```sh
# 予想レポート（馬場を指定） → predictions/<race_id>.md
python3 predict.py 202606040911 --going 重

# 自分の買い目を評価
python3 predict.py 202606040911 --going 重 --axis 15 --rivals 11 13 --others 14 3 16 10 9 6

# 買い目の記録 → レース後に結果を記録 → 成績比較
python3 record.py add 202606040911 --axis 15 --rivals 11 13 --others 14 3 16 10 9 6
python3 record.py settle
python3 record.py summary

# 過去の重賞で重みを学習・検証
python3 backtest.py
```

Python 3.10以上、標準ライブラリのみ。買い方のルールと運用方法は [CLAUDE.md](CLAUDE.md) を参照。

## レポートの中身

- 展開予想: 位置取り傾向からペース（ハイ〜スロー）と隊列を予想
- 開催中の馬場傾向: 前日・当日の同じ芝ダ・同じ馬場状態のレースから前有利/内有利/時計（馬場状態が違う日は除外）
- 総合評価: 勝率・2着内率・3着内率、ベスト指数、相手関係、コース・馬場適性、位置取り、調教、評価を上げた/下げた要因
- 各馬の近走: タイム・スピード指数・ペース（前後3F）・通過順・上り・相手の指数・今回への参考度
- 相手関係: 負かした相手・負けた相手のその後の成績
- 騎手・調教師・騎手×調教師・騎手×コース・父・母父: 人気から期待される3着内率との差と回数（少ないものは参考外）
- 買い目: 指定の買い目とモデル自動選択の①〜④フォーメーション、的中確率、期待回収率

## 現在のモデル（2026-09-27 学習）

- 学習データ: JRA全クラス2,016レース（2023/01〜2026/09、うち重賞約240）。古い1,411Rで学習、新しい605Rで確認
- 確認用605Rでの精度（1〜3着の並びの対数尤度、大きいほど良い）: 市場オッズのみ -6.001 / モデル -6.002（ほぼ同じ）
  - 市場オッズに足して少しでも良くなったのは「タイム・相手関係」(-5.9995) と「展開」(-6.0000) だけ
- 北村式48点を毎レース買った場合（確認用605R）
  | 選び方 | 市場オッズで選ぶ | モデルで選ぶ |
  |---|---|---|
  | 確率順 | 的中26% / 回収率68% | **的中27% / 回収率77%** |
  | 軸2番手 | 22% / 67% | 23% / 77% |
  | 妙味相手 | 20% / 60% | 22% / 74% |
  | 妙味軸 | 11% / 71% | 12% / 63% |
- 学習した重み（市場1.21に対して）: 馬場適性 +0.12、平均指数 +0.07、条件経験 +0.04、騎手×コース +0.04、開催傾向 +0.04、父 +0.03、展開 +0.03、レース間隔 -0.04。
  騎手・調教師・騎手×調教師・母父は、回数ルールと向きの制限のもとで 0（人気に織り込み済み）
- 結論: 精度は人気とほぼ同じ。48点の買い方では、モデルで「確率順」に選ぶのが的中率・回収率とも最も安定。
  ただし回収率は100%を下回る（3連単の控除率は27.5%）

推定値はあくまで目安で、的中や利益を保証するものではありません。
